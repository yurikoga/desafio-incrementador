# 🚀 Desafio de POO: Auto-Incremento de IDs em Java

Projeto desenvolvido a partir de um desafio proposto em sala de aula durante os estudos de **Programação Orientada a Objetos (POO)**. O objetivo principal foi criar um mecanismo automatizado para gerar e controlar identificadores únicos (IDs) para cada novo objeto instanciado, sem a interferência ou entrada manual de dados pelo usuário.

---

## 💡 Conceitos Aplicados

O projeto serve como um ótimo exercício prático para fixar os seguintes pilares de POO e lógica em Java:

* **Classes e Objetos:** Modelagem da entidade principal e instanciação de múltiplos objetos.
* **Modificador `private`:** Proteção dos dados internos da classe contra alterações externas indesejadas.
* **Atributo `static`:** Uso de variáveis de classe compartilhadas entre todas as instâncias para manter o controle contínuo do contador de IDs.
* **Métodos de Auto-Incremento:** Lógica interna que atualiza o identificador a cada nova chamada/instanciação.
* **Manipulação de Vetores e Laços (`for`):** Armazenamento das instâncias em um array e validação do funcionamento da lógica por meio de iteração.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java
* **Conceitos:** Programação Orientada a Objetos (POO)
